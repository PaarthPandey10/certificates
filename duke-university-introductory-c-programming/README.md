## Overview

This repository contains all course completion certificates and related materials from the *Introduction to C Programming* Specialization offered by **Duke University** on **Coursera**.  
The specialization provides a solid foundation in programming using the C language — covering fundamental programming concepts, problem-solving techniques, and algorithmic thinking.

## Key Highlights

- Comprehensive understanding of **C programming syntax**, variables, loops, functions, and arrays.  
- Development of **modular programs** using functions and structured design principles.  
- Application of **logic building and debugging** techniques to real-world problems.  
- Exposure to **algorithmic thinking**, including sorting, searching, and recursion.  
- Hands-on coding experience through interactive programming assignments and peer-reviewed projects.
