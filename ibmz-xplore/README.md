# IBM Z Xplore

> Hands-on training in enterprise computing, z/OS architecture, and mainframe modernization.

---

## Overview

This repository documents my progress through the **IBM Z Xplore** learning platform. The program covers a wide range of industry-standard technologies used in mainframe environments, moving from basic connectivity to advanced system programming and automation.

---

## Key Highlights

- **Fundamentals:** Connectivity, JCL, USS, and Python automation using Z Open Automation Utilities (ZOAU).
- **Concepts:** Enterprise architecture, virtualization, security, and hardware fundamentals.
- **Advanced:** Low-level programming with High Level Assembler (HLASM), REXX scripting, and system administration.
- **Tools:** VS Code, Zowe Explorer, IBM Z Open Editor, and SSH.
